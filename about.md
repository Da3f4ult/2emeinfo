# Toutes les balises HTML et leurs descriptions

Ce document présente une liste des balises HTML, avec une description en français.  
Les balises HTML5 sont incluses, ainsi que certaines balises obsolètes.

## Balises de structure de base

| Balise | Description |
|--------|-------------|
| `<!DOCTYPE>` | Déclare le type de document et la version HTML. |
| `<html>` | Élément racine d'une page HTML. |
| `<head>` | Contient les métadonnées du document. |
| `<title>` | Définit le titre de la page (affiché dans l'onglet). |
| `<body>` | Contient le contenu visible de la page. |
| `<meta>` | Fournit des métadonnées sur le document (encodage, description, etc.). |
| `<link>` | Lie une ressource externe (feuille de style, favicon). |
| `<style>` | Intègre des styles CSS dans le document. |
| `<script>` | Intègre ou référence du code JavaScript. |
| `<base>` | Spécifie l'URL de base pour tous les liens relatifs. |
| `<noscript>` | Contenu alternatif si JavaScript est désactivé. |

## Balises de sectionnement

| Balise | Description |
|--------|-------------|
| `<header>` | En-tête d'une page ou d'une section. |
| `<nav>` | Zone de navigation contenant des liens. |
| `<main>` | Contenu principal et unique de la page. |
| `<section>` | Section générique d'un document. |
| `<article>` | Contenu autonome (article de blog, actualité). |
| `<aside>` | Contenu en marge (barre latérale, publicité). |
| `<footer>` | Pied de page d'une page ou d'une section. |
| `<address>` | Coordonnées de contact de l'auteur ou de l'entreprise. |

## Balises de groupement de contenu

| Balise | Description |
|--------|-------------|
| `<div>` | Conteneur générique de bloc. |
| `<span>` | Conteneur générique en ligne. |
| `<p>` | Paragraphe. |
| `<hr>` | Ligne horizontale de séparation. |
| `<pre>` | Texte préformaté (espaces et sauts de ligne conservés). |
| `<blockquote>` | Citation en bloc. |
| `<ol>` | Liste ordonnée. |
| `<ul>` | Liste non ordonnée. |
| `<li>` | Élément d'une liste. |
| `<dl>` | Liste de définitions. |
| `<dt>` | Terme d'une liste de définitions. |
| `<dd>` | Description d'un terme. |
| `<figure>` | Illustration, diagramme, photo. |
| `<figcaption>` | Légende d'une figure. |

## Balises de texte en ligne

| Balise | Description |
|--------|-------------|
| `<h1>` à `<h6>` | Titres de section, du plus important (h1) au moins important (h6). |
| `<br>` | Saut de ligne. |
| `<abbr>` | Abréviation ou acronyme. |
| `<b>` | Texte en gras, sans importance particulière. |
| `<strong>` | Texte important, généralement en gras. |
| `<i>` | Texte en italique, sans importance particulière. |
| `<em>` | Texte mis en emphase, généralement en italique. |
| `<mark>` | Texte surligné. |
| `<small>` | Texte de petite taille (mentions légales). |
| `<del>` | Texte supprimé (barré). |
| `<ins>` | Texte inséré (souligné). |
| `<sub>` | Indice. |
| `<sup>` | Exposant. |
| `<code>` | Fragment de code informatique. |
| `<kbd>` | Saisie au clavier. |
| `<samp>` | Sortie d'un programme. |
| `<var>` | Variable informatique. |
| `<cite>` | Titre d'une œuvre. |
| `<q>` | Citation courte en ligne. |
| `<dfn>` | Terme en cours de définition. |
| `<time>` | Date ou heure. |
| `<data>` | Valeur lisible par machine. |
| `<ruby>` | Annotation ruby pour la prononciation (langues asiatiques). |
| `<rt>` | Annotation ruby. |
| `<rp>` | Parenthèses pour les navigateurs ne supportant pas ruby. |
| `<bdi>` | Isolation bidirectionnelle du texte. |
| `<bdo>` | Direction du texte. |
| `<wbr>` | Opportunité de coupure de mot. |
| `<u>` | Texte souligné (annotation non textuelle). |
| `<s>` | Texte barré (information obsolète). |

| `<font>` | Obsolète, utiliser CSS. |

| `<frameset>` | Obsolète. |
| `<isindex>` | Obsolète. |
| `<keygen>` | Obsolète. |
| `<marquee>` | Obsolète, texte défilant. |
| `<menuitem>` | Obsolète. |
| `<noframes>` | Obsolète. |
